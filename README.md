# parsing_dns_shop
Нужно создать web-приложение, которое будет собирать информацию о товарах с сайта dns-shop.ru город любой

Собрать нужно полный список товара из любых 5 категорий нижнего уровня и сохранить его в Exсel таблице
Сохранить нужно следующую информацию о товаре:

Категорию
Наименование
Цена
доступен или нет к продаже
Ссылка страницы с товаром
Ссылку на главное изображение
Ссылки на все изображения
Характеристики
Описание

в результате нужно показать
